# Econometrics II - ARMA Practice
This project applies basic time series analysis to financial price data using R.
The analysis explores price dynamics, trend behavior, residual structure, and ARMA modeling for short-run financial series.
## Objective
The objective is to practice time series modeling and evaluate whether ARMA-type models can describe short-term movements in financial data.
## Tools
- R
- readxl
- forecast
- lmtest
## Skills demonstrated
- Time series visualization
- Trend modeling
- Residual analysis
- ARMA modeling
- Financial data interpretation
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding financial price dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics II assignment. This repository contains a cleaned version prepared for portfolio purposes.
