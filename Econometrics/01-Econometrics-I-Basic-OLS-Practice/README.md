# Econometrics I - Basic OLS Practice
This project contains introductory econometrics exercises using R.
The analysis estimates simple linear regression models and interprets coefficients, goodness of fit, and the relationship between education and labor income.
## Objective
The objective is to practice basic Ordinary Least Squares (OLS) estimation and interpretation using household survey data.
## Tools
- R
- foreign
- haven
- dplyr
- ggplot2
## Skills demonstrated
- Simple linear regression
- Coefficient interpretation
- R-squared interpretation
- Household survey data handling
- Basic econometric reasoning
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding household survey dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics I assignment. This repository contains a cleaned version prepared for portfolio purposes.
