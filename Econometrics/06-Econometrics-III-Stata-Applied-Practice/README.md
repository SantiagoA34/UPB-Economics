# Econometrics III - Applied Stata Practice
This project contains applied Stata exercises using household survey data.
The script constructs variables related to health insurance, demographic characteristics, labor income, education, and social protection indicators.
## Objective
The objective is to practice data preparation and variable construction in Stata for applied econometric analysis.
## Tools
- Stata
## Skills demonstrated
- Variable recoding
- Dummy variable construction
- Labeling variables
- Survey data preparation
- Applied data management in Stata
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding survey dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics III assignment. This repository contains a cleaned version prepared for portfolio purposes.
