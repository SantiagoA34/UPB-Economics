# Econometrics I - Final Applied Practice
This project contains a final applied econometrics practice using household survey data in R.
The analysis constructs variables such as experience, gender, and urban status, and applies econometric models to study labor market outcomes.
## Objective
The objective is to apply core Econometrics I tools to real survey data and interpret labor income models in an applied setting.
## Tools
- R
- dplyr
- tidyr
- readxl
- foreign
- haven
- lmtest
- sandwich
- AER
## Skills demonstrated
- Survey data preparation
- Dummy variable construction
- Wage equation estimation
- Applied OLS modeling
- Econometric interpretation
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding household survey dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics I assignment. This repository contains a cleaned version prepared for portfolio purposes.
