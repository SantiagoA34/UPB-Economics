# Econometrics I - Robust Inference Practice
This project applies econometric models to household survey data using R.
The analysis estimates wage equations and evaluates heteroskedasticity using formal tests. It also introduces robust inference for linear regression models.
## Objective
The objective is to estimate labor income models and evaluate whether standard OLS inference is affected by heteroskedasticity.
## Tools
- R
- dplyr
- readxl
- haven
- foreign
- lmtest
- sandwich
## Skills demonstrated
- Multiple linear regression
- Log-linear wage models
- White test for heteroskedasticity
- Robust standard errors
- Econometric interpretation
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding household survey dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics I assignment. This repository contains a cleaned version prepared for portfolio purposes.
