# UPB-Economics
This repository contains selected coursework and applied projects developed during my undergraduate studies in Economics at Universidad Privada Boliviana (UPB).
The projects include work in economics, econometrics, statistics, impact evaluation, and data science using R, Stata, and Python.
## Areas covered
- Econometrics
- Statistics
- Data Science
- Impact Evaluation
- Time Series
- Panel Data
- Public Economics
- Applied Economics
## Tools
- R
- Stata
- Python
- Jupyter Notebook
- Excel
## Purpose
This repository serves as an academic portfolio to document my technical and analytical work in economics and data analysis.
