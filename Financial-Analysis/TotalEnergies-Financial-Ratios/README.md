# TotalEnergies Financial Ratios Analysis
This project analyzes TotalEnergies SE's financial performance between 2016 and 2024 using financial ratios and data visualization in R.
The analysis includes profitability margins, efficiency indicators, Brent oil price context, CAPEX composition, and the cash conversion cycle.
## Objective
The objective is to evaluate TotalEnergies' financial performance, capital allocation, and transition strategy through selected financial ratios and visualizations.

The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding financial Excel files and update the file paths in the script if needed.
