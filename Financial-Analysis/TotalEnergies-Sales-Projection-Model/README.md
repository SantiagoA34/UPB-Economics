# TotalEnergies Sales Projection Model
This project builds a 10-year sales projection model for TotalEnergies SE using Brent oil price scenarios.
The analysis estimates an OLS regression linking TotalEnergies' net sales to the annual Brent oil price and uses IEA scenario assumptions to project sales between 2025 and 2034.
## Objective
The objective is to evaluate how future Brent price scenarios could affect TotalEnergies' projected sales.
