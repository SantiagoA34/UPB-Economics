# Tourism ANOVA Analysis in Bolivia
This project applies statistical analysis to tourism data from Bolivia using R.
The analysis explores tourism patterns across departments and months, using descriptive statistics, data visualization, and Analysis of Variance (ANOVA) to evaluate whether differences across groups are statistically significant.
## Objective
The objective is to analyze whether tourism activity differs significantly across Bolivian departments and time periods.
## Tools
- R
- readxl
- dplyr
- tidyr
- ggplot2
## Skills demonstrated
- Data cleaning
- Data transformation
- Exploratory data analysis
- Data visualization
- Two-way ANOVA
- Statistical interpretation
## Data
The original dataset is not included in this repository.
To reproduce the analysis, add the corresponding tourism dataset and update the file path in the R script if needed.

This project was originally developed as part of an undergraduate statistics assignment. This repository contains a cleaned version prepared for portfolio purposes.
