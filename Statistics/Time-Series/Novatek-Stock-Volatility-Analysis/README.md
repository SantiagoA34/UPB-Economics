# NOVATEK Stock Volatility Analysis
This project analyzes weekly stock price behavior for NOVATEK between 2018 and 2023 using R.
The analysis explores closing prices, weekly percentage changes, trading volume, weekly price range, volatility episodes, and the behavior of the stock around major economic and geopolitical events.
## Objective
The objective is to examine how NOVATEK's stock price and trading volume evolved over time and identify periods of higher volatility.
## Tools

- readxl

## Skills demonstrated
- Financial data analysis

- Event-based analysis
- Correlation analysis

## Data
The original dataset is not included in this repository.
To reproduce the analysis, add the corresponding NOVATEK dataset and update the file path in the R script if needed.
