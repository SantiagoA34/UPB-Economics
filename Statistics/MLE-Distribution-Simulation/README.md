# Maximum Likelihood Estimation Simulation Study
This project applies Maximum Likelihood Estimation (MLE) to simulated probability distributions using Python.
The analysis simulates random samples from selected probability distributions, estimates their parameters through MLE, and compares the estimated values with the true parameters used in the simulation.
## Objective
The objective is to understand how Maximum Likelihood Estimation works in practice and evaluate how accurately it can recover the parameters of known probability distributions.
