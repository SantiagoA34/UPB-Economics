# Probability Distributions Review
This notebook reviews selected probability distributions using Python.
The project includes examples, simulations, and visualizations related to discrete and continuous probability distributions studied in an undergraduate statistics course.
## Objective
The objective is to strengthen understanding of probability distributions through computational examples and graphical analysis.
## Tools
- Python
- Jupyter Notebook
- NumPy
- Pandas
- SciPy
- Matplotlib
## Topics covered
- Probability distributions
- Simulation
- Probability mass functions
- Probability density functions
- Data visualization
- Statistical interpretation
## Files
- `notebooks/probability_distributions_review.ipynb`: main notebook containing the distribution review.
## Academic context
This project was originally developed as part of an undergraduate statistics assignment. This repository contains a cleaned version prepared for portfolio purposes.
