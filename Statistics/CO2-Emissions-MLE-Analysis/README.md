# CO2 Emissions MLE Analysis
This project analyzes the distribution of country-level CO₂ emissions per capita using Maximum Likelihood Estimation (MLE) in R.
The analysis applies a natural logarithm transformation to CO₂ emissions per capita and fits a Normal distribution to the transformed variable. It also computes descriptive statistics such as the median, standard deviation, skewness, and kurtosis.
## Objective
The objective is to characterize the statistical distribution of CO₂ emissions per capita and evaluate whether a log-normal modeling approach provides a reasonable approximation.
