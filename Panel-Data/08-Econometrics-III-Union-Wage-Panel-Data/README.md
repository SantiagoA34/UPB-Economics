# Econometrics III - Union Wage Panel Data Final Project
This project analyzes the relationship between union membership and wages using panel data.
The analysis uses the `wagepan` dataset structure and compares different panel data approaches, including pooled OLS, random effects, and fixed effects models.
## Objective
The objective is to estimate the association between union membership and log wages while accounting for unobserved individual heterogeneity.
## Tools
- Stata
## Skills demonstrated
- Panel data declaration
- Descriptive statistics
- Pooled OLS
- Random effects
- Fixed effects
- Robust inference
- Panel data interpretation
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding `wagepan.dta` dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics III final project. This repository contains a cleaned version prepared for portfolio purposes.
