# Econometrics III - Airfare Panel Data Analysis
This project estimates the effect of market concentration on airfares using panel data for U.S. airline routes.
The analysis compares pooled OLS, random effects, and fixed effects specifications while controlling for distance and year effects.
## Objective
The objective is to evaluate how market concentration affects airfare prices using panel data methods.
## Tools
- Stata
## Skills demonstrated
- Panel data setup
- Pooled OLS
- Robust standard errors
- Random effects models
- Fixed effects models
- Model comparison
- Applied microeconometric interpretation
## Data
The dataset used for this project is not included in this repository.
To reproduce the analysis, add the corresponding AIRFARE panel dataset and update the file path in the script if needed.
## Academic context
This project was originally developed as part of an undergraduate Econometrics III assignment. This repository contains a cleaned version prepared for portfolio purposes.
